Instructions never overlap, so no hazard can occur. There is no forwarding, no stall and no flush logic.
There is no ALU-result register and no memory-data register. The instruction register holds its value for the whole instruction, so every value derived from it is already steady. Removing both registers saves 64 flip-flops and changes no behaviour.

ENCODING
All seven R-type families share opcode 0110011 and are separated by funct7 alone: 0000000 and 0100000 base ALU, 0000001 Zmmul, 1000000 Xicrc. The decoder is two-level, not a 47-way lookup.
THE TWO EXTENSIONS
Zmmul adds MUL, MULH, MULHSU, MULHU with no divider. Xicrc computes CRC-16/CCITT-FALSE — polynomial 0x1021, seed 0xFFFF, MSB-first — over 8, 16 and 32 bits with zero latency.

INSTRUCTION-LEVEL DETAIL
A custom CRC instruction executing in four cycles
wave_instruction.png — 2.41:1
INSTRUCTIONCRCB
ENCODING0x80848433
OPERAND0x12
CHECKSUM IN0xFFFF
RESULT0xD383
Matches the standard CRC-16/CCITT-FALSE algorithm.
WHY THIS FRAME MATTERS
Four units compute an answer from the same two operands at the same time. wb_src_sel picks which one reaches the register file — it reads 2 crc here. The CRC block is combinational, so its result is already settled during DECODE, one full cycle before WRITEBACK needs it. That is why this processor needs no result register between states.

INSTANCE ORDER IS AN AREA KNOB
Moving one block in the instance list, changing no logic at all, moved cell area by 12 %. A cell-count difference between two runs is not by itself evidence that the design changed.
DIODE INSERTION COST 19.5 % FOR NOTHING
Heuristic insertion placed 9,838 antenna diodes and left exactly the same residual violating nets as targeted repair with 325. Disabling it shrank the die by 19.5 %.
FREQUENCY, STATED HONESTLY
The flow reports 30.303 MHz, but that only echoes the 33 ns constraint. With +2.25 ns of slack the design closes near 32.5 MHz on this run. Treat 33 ns as the guarantee, not the maximum.
